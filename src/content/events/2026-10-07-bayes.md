We took a closer look at the math behind Black-Litterman by connecting it to Bayes' theorem. The big idea is that the model is really just a Bayesian update: the market's implied return acts as the prior, an investor's view acts as new evidence, and the Black-Litterman output is the posterior that blends the two. We built an interactive tool in Python with sliders for the prior return, prior uncertainty, view return and view confidence, then watched in real time how the probability distributions shifted as we changed each input. It built intuition for why a confident view pulls the posterior hard toward it, while a weak view barely moves it away from the market.
